# Build APK from your phone
1. Create a GitHub repository in your phone browser.
2. Upload the contents of this folder.
3. Open **Actions** → **Build RK Billing APK** → **Run workflow**.
4. When it finishes, open the workflow run → **Artifacts** → download the APK.
5. Install the APK on Android (allow installation from your browser/files app if Android asks).

No laptop is required, but a GitHub account and internet connection are required for this cloud build.
