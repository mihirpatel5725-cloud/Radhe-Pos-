# Radhe Kathiyawadi — Mobile PWA
Open `index.html` through a web server/hosting service. On Android Chrome use **Add to Home screen** to install it like an app.

Included:
- Gujarati / English
- Fast Billing
- KOT, Tables, Items/Stock, Customer, Reports placeholders
- Printer settings: Bluetooth / USB / Network
- 58 mm / 80 mm
- Auto Print, KOT print, Duplicate bill settings
- Offline cache (PWA)

This PWA is ready for phone use. Real Bluetooth/USB thermal printing requires browser/device support or a native Android build.
